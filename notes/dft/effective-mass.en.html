Effective Mass Calculation

Published 2026-06-04

Definition

Effective mass originates from band curvature. \[ \frac{1}{m^*}=\frac{1}{\hbar^2}\frac{\partial^2 E}{\partial k^2}. \] The effective mass is a tensor, so electric fields applied along different directions correspond to different effective masses. \[ \frac{1}{m^*_{ij}}=\frac{1}{\hbar^2}\frac{\partial^2 E}{\partial k_i \partial k_j}. \]

Calculation Workflow

First, perform an SCF calculation to obtain converged CHGCAR and WAVECAR files, and then use vaspkit-911 to locate the CBM and VBM \(k\) points. Second, sample \(k\) points near the CBM and VBM and perform an NSCF calculation with the converged CHGCAR to obtain EIGENVAL. Third, use the fitting script to extract the effective-mass tensor from EIGENVAL.

SCF

First, perform the SCF calculation in 2_scf/ to obtain a converged CHGCAR. The key SCF settings in INCAR are:

ISTART  = 0
ICHARG = 2
LWAVE   = .TRUE.
LCHARG  = .TRUE.

NSCF

Next, perform a fixed-charge-density NSCF calculation in 4_nscf/, evaluating eigenvalues only at k points near the CBM and VBM. The key NSCF settings in INCAR are:

ISTART  = 1
ICHARG = 11
LWAVE   = .FALSE.
LCHARG  = .FALSE.
ISYM   = 0

The NSCF KPOINTS must lie near the VBM and CBM. They can be generated with the following script:

python generate_kpoints.py \
  --poscar POSCAR \
  --h 0.01 \
  --cbm 0 0 0 \
  --vbm 0.4651 0.5 0 \
  --out KPOINTS_test

This generates:

  • KPOINTS_test: 54 \(k\) points near the VBM and CBM.

  • KPOINTS_test.json: a record of how each \(k\) point was generated.

Rename KPOINTS_test as KPOINTS.

Fitting the Effective Mass

Fit the effective mass using the EIGENVAL and json files obtained in the previous step:

python fit_effective_mass.py \
  --eigenval EIGENVAL \
  --metadata KPOINTS_test.json \
  --cband 57 \
  --vband 56 \
  --poscar POSCAR \
  --field-direct 1 0 0

Here, the band indices of the CBM and VBM must be specified. The final --field-direct option selects the direction along which the reduced effective mass is calculated, using the real-space lattice vectors as the basis. The effective mass is then displayed directly in the terminal.
