Electron–Phonon Coupling Calculation

Published 2026-06-05

Definition

The electron–phonon coupling matrix element is defined as \[ g_{mn\nu}(\mathbf{k},\mathbf{q}) = \left\langle \psi_{m,\mathbf{k}+\mathbf{q}} \middle| \partial_{\nu\mathbf{q}} V \middle| \psi_{n,\mathbf{k}} \right\rangle . \] Here \(\ket{\psi_{n,\mathbf{k}}}\) is the initial state and \(\ket{\psi_{m,\mathbf{k}+\mathbf{q}}}\) is the final state. If the desired matrix element connects the VBM to the CBM, then \(m\), \(n\), \(\mathbf{k}\), and \(\mathbf{q}\) are fixed, leaving only the mode index \(\nu=1,\dots,3N\):

\[ g_{cv\nu}(\mathbf{k}_{v},\mathbf{q}) = \left\langle \psi_{c,\Gamma} \middle| \partial_{\nu\mathbf{q}} V \middle| \psi_{v,\mathbf{k}_{v}} \right\rangle , \]

Workflow

VASP 6.5.0 and later can calculate electron–phonon coupling matrix elements. The procedure is to generate the electron–phonon potential from finite displacements in a supercell and then return to the primitive cell to calculate the matrix elements:

  1. Run a static calculation to obtain the VBM/CBM \(k\) points and band indices.

  2. Apply finite displacements to the supercell and generate phelel_params.hdf5.

  3. In the primitive cell, use phelel_params.hdf5 to calculate the matrix elements and write vaspelph.h5.

  4. Extract \(\langle \psi_{c,\Gamma}|\partial_{\nu\mathbf{q}}V|\psi_{v,\mathbf{k}_{v}}\rangle\) from vaspelph.h5.

SCF

After structural optimization, run a high-accuracy SCF calculation to obtain the VBM and CBM \(k\) points and band indices.

Generate the hdf5 File

For the second step, first use phonopy to construct the supercell SPOSCAR. Rename SPOSCAR to POSCAR and submit the calculation. For an initial test, KPOINTS may use a 1\(\times\)1\(\times\)1 \(\Gamma\)-point mesh.

The essential INCAR settings are:

NSW    = 1
IBRION = 6
NFREE = 2
POTIM = 0.01

ELPH_POT_GENERATE = .TRUE.
ELPH_POT_FFT_MESH = 28 36 96

After the calculation finishes, it writes phelel_params.hdf5. This file contains the derivatives of the Kohn–Sham potential and the force-constant information required for the electron–phonon matrix-element calculation.

Note on CONTCAR_ELPH

VASP 6.5.0 does not write CONTCAR_ELPH. Starting with VASP 6.5.1, CONTCAR_ELPH is generated together with phelel_params.hdf5 and is used as the POSCAR for the next step. If CONTCAR_ELPH is unavailable, the original primitive-cell POSCAR can still be used, but it must match the primitive cell automatically identified by VASP in phelel_params.hdf5. The primitive-cell information can be checked in OUTCAR.

ELPH_POT_FFT_MESH must be kept consistent with the next step.

Because ELPH_POT_GENERATE has a bug in VASP 6.5.0, it is also advisable to specify the primitive-cell ELPH_POT_LATTICE used in the subsequent calculation, in addition to ELPH_POT_FFT_MESH.

Generate the h5 File

The third step calculates the electron–phonon coupling matrix elements in the primitive cell. The directory must contain:

POSCAR
POTCAR
INCAR
KPOINTS
KPOINTS_ELPH
phelel_params.hdf5

If CONTCAR_ELPH is available, copy it to POSCAR. Otherwise, use the primitive-cell POSCAR that matches phelel_params.hdf5.

This step requires two KPOINTS files. VASP first performs SCF iterations with KPOINTS until the charge density converges and then performs one NSCF step using KPOINTS_ELPH.

The essential INCAR settings are:

NSW    = 0
IBRION = -1
NGX = 28 # same as FFT mesh
NGY = 36
NGZ = 96
ELPH_RUN    = .TRUE. # calculate h5 file
ELPH_DRIVER = mels

KPOINTS only needs to define a uniform mesh.

KPOINTS_ELPH specifies the \(k\) points used to calculate the electron–phonon matrix elements:

VBM to CBM
2
Reciprocal
0.0000000000  0.0000000000  0.0000000000  1
0.4651162791  0.5000000000  0.0000000000  1

After these two points are selected, vaspelph.h5 contains every pairing between them: \[k_v \rightarrow k_v, \quad k_v \rightarrow \Gamma, \quad \Gamma \rightarrow k_v, \quad \Gamma \rightarrow \Gamma.\]

Extract Matrix Elements from vaspelph.h5

vaspelph.h5 contains several datasets, including:

/kpoints/vkpt_kp
/kpoints/vkpt_k
/matrix_elements/eigenvalues_kp
/matrix_elements/eigenvalues_k
/matrix_elements/phonon_eigenvalues
/matrix_elements/elph

The key dataset is /matrix_elements/elph, whose shape is \[\left\{ n_{\rm spin},\, n_{k'},\, n_{k},\, 3N,\, n_{{\rm band},k'},\, n_{{\rm band},k},\, 2 \right\}.\] The final dimension, \(2\), stores the real and imaginary parts of a complex number. \(n_{k'}\) and \(n_{{\rm band},k'}\) correspond to the final state, while \(n_{k}\) and \(n_{{\rm band},k}\) correspond to the initial state. The unit of /matrix_elements/elph is eV.

For example:

/matrix_elements/elph = {1, 2, 2, 42, 64, 1, 2}

This represents 1 spin component, 2 final-state \(k'\) points, 2 initial-state \(k\) points, 42 phonon branches, 64 final-state bands, and 1 initial-state band. With the specified KPOINTS_ELPH, the two \(k\) points are \(\Gamma\) and \((0.4651,0.5,0)\).

The remaining task is to extract the required slice of the dataset; a post-processing script can then be generated with Codex.
