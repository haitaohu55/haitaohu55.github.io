有效质量计算

发布于 2026-06-04

定义

有效质量来于能带的弯曲 \[ \frac{1}{m^*}=\frac{1}{\hbar^2}\frac{\partial^2 E}{\partial k^2}. \] 有效质量是一个张量，沿不同方向的电场会有不同的有效质量 \[ \frac{1}{m^*_{ij}}=\frac{1}{\hbar^2}\frac{\partial^2 E}{\partial k_i \partial k_j}. \]

计算流程

第一步做 SCF，得到收敛的 CHGCAR 和 WAVECAR，然后用 vaspkit-911 找 CBM 和 VBM 的 \(k\) 点位置。 第二步在 CBM 和 VBM 附近取 \(k\) 点用收敛的 CHGCAR 做 NSCF，得到 EIGENVAL。 第三步用拟合脚本从 EIGENVAL 拟合有效质量张量。

SCF

先在 2_scf/ 做 SCF，得到收敛的 CHGCAR。SCF 关键 INCAR 如下

ISTART  = 0
ICHARG = 2
LWAVE   = .TRUE.
LCHARG  = .TRUE.

NSCF

然后在 4_nscf/ 做固定电荷密度 NSCF，只在 CBM 和 VBM 附近的 k 点上求本征值。NSCF 关键 INCAR 如下

ISTART  = 1
ICHARG = 11
LWAVE   = .FALSE.
LCHARG  = .FALSE.
ISYM   = 0

NSCF 的 KPOINTS 需要在 VBM/CBM 附近，可以用脚本生成

python generate_kpoints.py \
  --poscar POSCAR \
  --h 0.01 \
  --cbm 0 0 0 \
  --vbm 0.4651 0.5 0 \
  --out KPOINTS_test

这会生成：

  • KPOINTS_test：54 个 VBM 和 CBM 附近的 \(k\) 点。

  • KPOINTS_test.json ：记录每一个 \(k\) 点怎么算的。

把 KPOINTS_test 重命名为 KPOINTS 就行。

拟合有效质量

基于上一步得到的 EIGENVAL 和 json 文件拟合有效质量

python fit_effective_mass.py \
  --eigenval EIGENVAL \
  --metadata KPOINTS_test.json \
  --cband 57 \
  --vband 56 \
  --poscar POSCAR \
  --field-direct 1 0 0

这里要指定 CBM 和 VBM 的 band index。 最后的 --field-direct 是你要沿着哪个方向算约化有效质量，实空间晶格矢量为基底。 最后在终端就会直接显示有效质量。
