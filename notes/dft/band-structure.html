能带计算

发布于 2025-11-16

准备

首先做结构优化，然后把新的 CONTCAR 命名为 POSCAR，放进文件夹 scf 中。

基本流程

一般算能带就是用结构优化后的 POSCAR 做一步自洽得到 WAVECAR 和 CHGCAR，然后用自洽得到的 WAVECAR 和 CHGCAR 跑能带计算。所以整个流程分两步：scf 和 band。

两步的 KPOINTS

自洽的 KPOINTS一般长这样

K-Points
0
Gamma
6 6 1
0 0 0

scf 完要算能带就需要给一条 \(k\) 空间的路径，KPOINTS 长这样

K-Points
40
Line-mode
rec
0.000 0.000 0.000
0.500 0.000 0.000

0.500 0.000 0.000
0.333 0.333 0.000

0.333 0.333 0.000
0.000 0.500 0.000

0.000 0.500 0.000
0.000 0.000 0.000

两步的 INCAR

两步的 INCAR 文件区别主要在

ISTART  = 0
ICHARGE = 2
# or
ISTART  = 1
ICHARGE = 11

以及他们需要什么文件上。对于自洽可以用

LWAVE   = .TRUE.
LCHARG  = .TRUE.

对于能带可以用

LWAVE   = .FALSE.
LCHARG  = .FALSE.

其他保持一致就可以了。

生成 band.dat

提交完任务后，用 vaspkit - 211 就能生成 band.dat 文件。
