Phonon Spectrum Calculation

Published 2026-05-17
Contents

    Preparation

    First optimize the structure, typically using the smallest primitive cell. Then rename the new CONTCAR as POSCAR and place it in the phonon folder.

    Place the band.conf template, the files folder (containing INCAR and KPOINTS), and job_phonon.slurm in the phonon folder.

    Upload phonon to the server, generate POTCAR with vaspkit 103, and place it in the files folder.

    Generate Displaced Supercells with Phonopy

    Enter the phonon folder and use phonopy to generate displaced supercells. On the Sugon platform, install it from the app store. After installation, first add it to the environment:

    module use /public/software/modules /opt/hpc/software/modules
source /public/home/chris_55/apprepo/phonopy/2.23.1-py3.12/scripts/env.sh

    Then generate the displaced supercells with the following command template:

    phonopy -d --dim="2 1 1" -c POSCAR

    The following files will then be generated in this folder:

    • SPOSCAR: the reference supercell.

    • POSCAR-001, POSCAR-002, and so on: each file is a displaced supercell.

    Modify KPOINTS

    KPOINTS may need to be adjusted according to the dimensionality of the system. Upload the modified file to the server again.

    Modify the Slurm Script

    Use the slurm template and adjust the loop range:

    for i in {001..002}

    Upload the file to the server and then submit the job.

    Generate FORCE_SETS

    Run the following command in the directory containing POSCAR, phonopy.yaml/SPOSCAR, and the disp-XXX/vasprun.xml files:

    phonopy --vasp -f disp-*/vasprun.xml

    After the command succeeds, FORCE_SETS will appear in the directory.

    band conf

    Update the path in the band.conf template, place the file in the directory, and run:

    phonopy -p band.conf

    This produces the band.yaml file.

    Plotting

    Plot the result with the bandplot function provided by phonopy:

    phonopy-bandplot --output band.pdf band.yaml

    Analyzing Vibrational Modes

    Use the following website:

    https://henriquemiranda.github.io/phononwebsite/phonon.html

    The vibrational modes can then be viewed directly. An imaginary frequency (negative frequency) at any point indicates that the structure is dynamically unstable.

    Key Point

    1. The phonon spectrum is generally calculated using a primitive cell. In vaspkit, option 6-602 can generate the smallest cell from a conventional cell.
