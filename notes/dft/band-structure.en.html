Band Structure Calculation

Published 2025-11-16

Preparation

First optimize the structure. Then rename the new CONTCAR as POSCAR and place it in the scf folder.

Basic Workflow

A band-structure calculation generally uses the optimized POSCAR for an SCF calculation that produces WAVECAR and CHGCAR. The resulting WAVECAR and CHGCAR are then used for the band-structure calculation. The complete workflow therefore has two steps: scf and band.

KPOINTS for the Two Steps

The KPOINTS file for the SCF calculation typically looks like this:

K-Points
0
Gamma
6 6 1
0 0 0

After the scf calculation, the band-structure calculation requires a path through \(k\) space. The KPOINTS file looks like this:

K-Points
40
Line-mode
rec
0.000 0.000 0.000
0.500 0.000 0.000

0.500 0.000 0.000
0.333 0.333 0.000

0.333 0.333 0.000
0.000 0.500 0.000

0.000 0.500 0.000
0.000 0.000 0.000

INCAR for the Two Steps

The main difference between the two INCAR files is:

ISTART  = 0
ICHARGE = 2
# or
ISTART  = 1
ICHARGE = 11

The files required by the two steps also differ. For the SCF calculation, use:

LWAVE   = .TRUE.
LCHARG  = .TRUE.

For the band-structure calculation, use:

LWAVE   = .FALSE.
LCHARG  = .FALSE.

All other settings can remain the same.

Generate band.dat

After the job finishes, use vaspkit - 211 to generate the band.dat file.
