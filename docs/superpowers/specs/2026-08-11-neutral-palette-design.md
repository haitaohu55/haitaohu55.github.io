# 个人主页中性配色设计

## 目标

把现有偏青的界面色板替换为真正的中性灰阶与单一蓝色强调，消除粉彩青带来的廉价感，同时保持当前页面的内容、布局、字体、圆角和导航结构不变。

访客仍应首先看到姓名、研究方向、笔记和论文；界面颜色只负责建立层级与标示可交互内容，不与科研信息争夺注意力。

## 设计依据

- Apple 的做法不是给所有区域染色，而是让白色、近白灰、深浅文字和少量蓝色各自承担稳定的语义角色。
- GitHub Primer 与 Vercel Geist 同样通过中性背景、明确边线和单一强调色建立层级。
- 这次迁移的是“语义层级与克制”，不复制 Apple 的营销布局、字体、玻璃材质或动画。

## 核心色板

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 中性画布 | `#F5F5F7` | 页面背景、顶栏背景、目录和代码块的弱背景 |
| 主表面 | `#FFFFFF` | 简介卡片、内容区块、笔记正文 |
| 主文字 | `#1D1D1F` | 姓名、标题、正文、顶栏主文字 |
| 次文字 | `#515154` | 摘要正文和需要比元数据更清晰的辅助信息 |
| 弱文字 | `#6E6E73` | 导航、学校、作者、日期和元数据 |
| 规则线 | `#D2D2D7` | 卡片边界、分隔线、顶栏底线和摘要竖线 |
| 交互蓝 | `#0066CC` | 链接、标题左线、当前导航和键盘焦点 |

悬停色从交互蓝派生为 `#004A99`，不引入新的色相。阴影统一使用主文字的低透明度版本 `rgba(29, 29, 31, 0.05)`。

## 映射规则

- 顶栏和页面画布使用同一中性背景，依靠细规则线而不是浅青色块分层。
- 所有原有青灰主文字统一为主文字；导航和元数据统一为弱文字。
- 所有原有青色链接、当前状态、章节竖线和焦点轮廓统一为交互蓝。
- 原有硬编码的摘要文字、目录背景、代码块背景和焦点颜色必须纳入同一语义色板。
- 交互蓝不用于普通装饰文字；链接之外的信息层级继续依靠字号、字重和灰度。

## 范围边界

本轮只允许调整 `assets/site.css` 中的颜色 token、硬编码颜色和阴影颜色，并更新对应的自动检查。不得修改：

- HTML 文案和链接；
- 页面结构、间距、宽度、圆角或断点；
- 字体、字号和字重；
- 笔记内容、图片、公式或代码；
- GitHub 远端内容。

## 验收标准

1. 原色板中的粉彩青、青灰和青绿强调色不再出现在共享样式中。
2. 全站只保留中性灰阶与同一蓝色家族作为界面色。
3. 正文、弱文字、链接和焦点状态满足相应的可读性与对比度要求。
4. 首页、Notes、Publications 和至少一个笔记详情页在桌面、390px 与 320px 下无新增溢出或视觉断层。
5. 页面内容与结构没有变化，16 个 HTML 页面的链接与共享样式检查继续通过。
6. 改动只保存在本地 `v1` 分支，不推送到 GitHub。
